# NFA to Regular Grammar Converter

A browser-based tool that converts a Non-deterministic Finite Automaton (NFA) into an equivalent Regular Grammar (RG) — built for a Theory of Automata / Formal Languages course.

## Tech Stack

- **HTML / CSS / JavaScript**

## Getting Started

No build step or dependencies required — this runs entirely in the browser.

```bash
git clone https://github.com/Ahmeds168/NfaToRg.git
cd NfaToRg
open index.html   # or double-click index.html in your file explorer
```

## How it works

Enter or configure an NFA's states, alphabet, and transitions via the UI in `index.html`; the logic in `main.js` converts it into the corresponding Regular Grammar rules, which are displayed on the page.
